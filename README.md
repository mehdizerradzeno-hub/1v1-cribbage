# 1v1 Cribbage

A self-contained, browser-based Cribbage table for local play against a bot. It follows standard two-player scoring: discard to the crib, pegging to 31, starter-card heels, fifteens, pairs, runs, flushes, nobs, and first to 121.

The first public release is intentionally local-versus-bot. Multiplayer and accounts will be connected to the existing Cribbage service work in a later release.

## Run locally

Open `index.html` in a browser, or serve this directory with any static HTTP server.
